# Stage 04 — Perception-to-Planner Contract Under Uncertainty

**Time:** 69–76 minutes  
**Mode:** facilitator demo; participants observe and discuss  
**Scenario:** `uncertainty`

This demo prevents the workshop from looking like formal verification is only
about finite-state machines. A planner receives a set of possible obstacle
positions instead of one guessed position.

## Demo steps

1. [`01-show-the-point-estimate-failure`](01-show-the-point-estimate-failure/README.md)
2. [`02-switch-to-a-set-valued-contract`](02-switch-to-a-set-valued-contract/README.md)
3. [`03-show-the-universal-lean-claim`](03-show-the-universal-lean-claim/README.md)

## Participant requirement

No previous exercise must be complete. This is a conceptual demonstration with
a compact one-dimensional model.
