# Model and Data Policy

- Gemini is an optional planner and tutor, not a proof authority.
- Lean Copilot is the default local assistant.
- Additional local or cloud models may be compared under the same kernel gate.
- Do not send confidential research, participant personal data, or secrets to a
  cloud model.
- Record the model identifier and configuration when reporting comparisons.
- Present failures honestly; a rejected candidate is useful workshop evidence.
