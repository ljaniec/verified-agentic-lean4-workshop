# Local participant workspace

Keep copied exercises under `playground/current/`, which is ignored by Git.
Save an existing attempt before replacing it with a different starter.

```bash
mkdir -p playground/current
cp course/browser/starters/01_LifecycleResources.lean playground/current/Current.lean
# Edit only the final proof.
./workshop browser check playground/current/Current.lean
```

Use the [browser task guide](../course/browser/README.md) during the event.
Do not commit participant attempts or backups.
