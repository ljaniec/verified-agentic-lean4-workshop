# Live demonstration script

The current script is the supplied **[agenda / task talk hints](../presentation/workshop-agenda.pdf)**.
Use it with the **[presentation](../presentation/workshop-slides.pdf)** and
**[browser task guide](../course/browser/README.md)**.

Follow the stops at 4, 12, 23, 29, 35, 42, and 45 minutes. Paste one complete
self-contained task at a time. Show the actual checker result for each completed
checkpoint. Task 05 intentionally starts with rejection; replace `rfl` with
`decide` only after displaying the real diagnostic.

See the [facilitator guide](facilitator-guide.md) for delivery cues and the
[rehearsal checklist](facilitator-rehearsal.md) for preflight and recovery.
The longer local curriculum and separate reference branches are not needed
for this browser sequence.
