# Claude Code entrypoint

Read and follow `AGENTS.md` as the canonical repository contract.

If `WORKSHOP_TASK.md` exists, read it next and complete only that task.

For that local checkpoint, use:

```bash
./workshop task status
./workshop task start
./workshop task check
```

Do not inspect a `-solution` branch unless explicitly requested.

For the browser event, follow `course/browser/README.md`. A copied local snippet
is checked with `./workshop browser check playground/current/Current.lean`.
On `main`, an explicit repository-maintenance request follows the maintenance
scope in `AGENTS.md`; it does not require a task-branch switch.
